How It Works

› from adversary intrusion to classified SOC alert

1. Decoy Trap

Fake login entrypoints (like an exposed SSH service) sit online pretending to be a real system. Attackers probe and attempt access without knowing it's a decoy.

→

2. Capture

Every incoming attempt — attacker IP address, timestamp, targeted port, and attempted passwords or web paths — gets safely recorded in real time.

→

3. Feature Extraction

Raw connection logs are transformed into numeric features our AI can analyze — such as request speed, packet size, headers, and port frequency.

→

4. ML Classification

Trained machine learning models served via FastAPI classify the activity into distinct threat categories (brute force, scanning, web recon, normal) in milliseconds.

→

5. Storage & Review

The classified incident is saved to a PostgreSQL database using SQLAlchemy, making threat history immediately queryable in the Attack Logs table.
